\section{Software and reproducibility}\label{app:repro}
%=====================================================================
The simulator, analysis and experiments are written in Python with NumPy~\cite{harris2020numpy}, SciPy~\cite{virtanen2020scipy} and Matplotlib~\cite{hunter2007matplotlib}. Convex problems are modelled with CVXPY~\cite{diamond2016cvxpy} and solved with Clarabel~\cite{goulart2024clarabel}, SCS~\cite{odonoghue2016scs} and OSQP~\cite{stellato2020osqp}; tests use pytest~\cite{pytest}. Package versions are pinned in \texttt{requirements.txt}. The code is available at \url{https://github.com/pranshuk22/quadrotor-rotor-loss-recovery}.

\begin{verbatim}
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q        # 122 pass + 1 expected failure
.venv/bin/python experiments/v0_validation_report.py
.venv/bin/python experiments/e1_equilibrium.py   # and e2 ... e10c
bash experiments/run_all.sh    # tests and all experiments
.venv/bin/python experiments/audit_numbers.py FILE.tex
\end{verbatim}

Each script writes a table to \texttt{results/tables/} and figures to \texttt{results/figures/}; all random seeds are fixed in the scripts (for example seeds 11, 12, 13 and 21 for the training, test and randomized data of E6). Runtimes are for an 8-core laptop without power throttling; E9c, E9d, E9e and E10b were slower or were run on cloud CPU kernels when time was short, which is stated with their results. Experiments E8c to E10c were pre-registered: the fixed choices are in the script docstring and the script was committed before its first run; the places where a first attempt was changed are listed in Section~\ref{sec:budget-dev}. The certificates of E9c are stored in \texttt{results/certificates/} and read by E9d.
