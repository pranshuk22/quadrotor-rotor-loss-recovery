\section{Software and reproducibility}\label{app:repro}
%=====================================================================
The simulator, analysis and experiments are written in Python with NumPy~\cite{harris2020numpy}, SciPy~\cite{virtanen2020scipy} and Matplotlib~\cite{hunter2007matplotlib}. Quadratic programs are modelled with CVXPY~\cite{diamond2016cvxpy} and solved with OSQP~\cite{stellato2020osqp}; tests use pytest~\cite{pytest}. Package versions are pinned in \texttt{requirements.txt}. The code is available at \url{https://github.com/pranshuk22/quadrotor-rotor-loss-recovery}.

\begin{verbatim}
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q        # 122 pass + 1 expected failure
.venv/bin/python experiments/v0_validation_report.py
.venv/bin/python experiments/e1_equilibrium.py   # one experiment
bash experiments/run_all.sh --report  # all tests and experiments
\end{verbatim}

Each script writes a table to \texttt{results/tables/} and figures to \texttt{results/figures/}. All random seeds are fixed in the scripts (for example seeds 11, 12, 13 and 21 for the training, test and randomized data of Section~\ref{sec:koopman}), and the settings of each experiment are written at the top of its script and were fixed before it was first run. Runtimes are for an 8-core laptop.
