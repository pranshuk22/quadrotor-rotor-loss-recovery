Data efficiency

Generalization fails

On the unseen plant B, both learned models are worse than the physics model alone. Training on randomized plants makes them worse: the unknown parameters cannot be read from one state sample.

Two more results, one good and one bad. Good: the residual model needs much less data. With only 10 short episodes it already beats the full-state model trained on 40. That matters because real failure data are scarce: failed flights tend to end in crashes. Bad: neither learned model generalizes to a plant with different parameters. On the held-out plant both are worse than the physics model alone. And training on many randomized plants did not help; it made them worse, because a static model cannot tell from a single state which vehicle it is on. This motivates our next step: adapt the residual online. Since the residual is linear in its parameters, recursive least squares is a natural, cheap choice.
