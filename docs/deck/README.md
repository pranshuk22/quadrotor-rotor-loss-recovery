# Slide deck: Progress review 1

**Files (ready to use):**
- [`progress-review-1.pptx`](progress-review-1.pptx): PowerPoint, 19 slides with speaker notes, theme and sections; editable in PowerPoint/Keynote
- [`progress-review-1.pdf`](progress-review-1.pdf): PDF export of the same deck (rendered with LibreOffice)

The .pptx is regenerated by `build_pptx.js` (pptxgenjs). Run it from a folder with pptxgenjs installed: `NODE_PATH=<that folder>/node_modules node build_pptx.js <pptx-skill-dir>`. The skill directory provides `scripts/apply_theme.js`. Speaker notes are read from `source/slides/*.html`, so the two versions share one set of notes.

**Live deck (online version):** https://claude.ai/artifact/ChBPoGhYr4JXZKfxSrnCLD
The deck is private until you share it from its Share menu. From the deck page you can present it and download it as **PowerPoint (.pptx)** or **PDF** (Share › Export).

**Sources:** `source/deck.json` (slide order and sections) and `source/slides/*.html` (one file per slide, including speaker notes in the `<aside>` element). These are copies for the record; edits should be made on the live deck.
