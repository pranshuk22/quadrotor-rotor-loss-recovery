## Known issues in the v1 PDF (fix if it is ever resubmitted)
- "Lee et al. 2024, Koopman FT-MPC" looks misattributed. The IET CTA paper is by Bakhtiaridoust et al.
- Sections 6–7 are missing (it jumps from §5 to §8).
- "Linear and time-invariant" holds only in Mueller & D'Andrea's reduced-attitude body-fixed coordinates.

## Changes after the first report (2026-11-13 onwards)

- **2026-11-13, E8a (offset-free baselines).** Added `rotorfail/offset_free.py`. The first design (thrust-offset disturbance, 3 states, as pre-registered) left a steady error on the nonlinear mismatched plants (-0.239 m on A) in a single pre-run check; the cause is structural (the steady-state innovation need not vanish with fewer disturbance states than unknown mismatch rows). A second disturbance model (7 physical states) was added and both were then run once under the same pre-registered settings (no estimator parameter was tuned); the MPC regulates the filtered estimate rather than the raw measurement. Results in `results/tables/e8_offset_free.md`.
- **2026-11-13, E8b (full-state Koopman MPC).** Added `LiftedKoopmanMPC`. The constant coordinate of the dictionary is excluded from the terminal-cost Riccati equation (including it made the solution very ill-conditioned). Comments in the pre-registration docstring and in `mpc.py` were reworded after the run (the number quoted for the condition number was removed because it is not produced by a committed script). Results in `results/tables/e8_full_koopman_mpc.md`.
- E7 re-run after adding code to `rotorfail/mpc.py`: table identical except the wall-clock timing line (4.3 against 4.4 ms).
- **2026-11-13, review fixes for stage B.** The E8a script text and `results/tables/e8_offset_free.md` received a note that E8a ran without the divergence rule used in E8b (height losses beyond about 100 m are not meaningful); no number changed, and the note was added to the table by hand with the same text as the script, so the table was not regenerated. A diagnostic run of the state-model capture failure was added (`experiments/e8a_diag_state_capture.py`, `results/tables/e8a_diag_state_capture.md`); it shows that the explanation "target outside the thrust limits" does not hold at 0 ms (all 43 pre-inversion targets were exact), and the report text was corrected. The tolerance of the lifted-MPC equivalence test was tightened to the measured 1.3e-7 N difference (4e-7 N). E8b was re-run to add the Riccati conditioning with the constant coordinate included to its model-check section.
- **2026-11-13, stage C (RQ2 foundations).** E9a (hand-over diagnostic), D3 (`rotorfail/lpv.py`), E9b (r-robust certificate), E9c (capture-gain synthesis, hand-over thresholds). Changes after first attempts, each first run kept as its own table: E9b run 1 (Euclidean remainder check failed for every box and kappa; replaced by the P-norm bound g_P) and run 2 (kappa grid too short; extended to 1e-4). The first launch of E9c stopped with an exception before any result (simulation window too short for thresholds of 14 rad/s and above). Plan deviations: z and v_z are kept in the closed loop (the LQR gain feeds them back); the plan's corner-box self-consistency condition is replaced by a disc condition (the box form cannot hold for any ellipsoid containing the hand-over state); the motor-state box is the physical thrust range (rotor 2 stopped is -1.02 N), not the saturation level; the remainder is checked after the solve; the fast-pole rule is 100 rad/s (the 10-state model's motor pole alone is at 67 rad/s).
- **2026-11-13, stage D (RQ2 main result).** `rotorfail/reach.py` (chain, Jacobian, containment SDP and trust-region cross-check, affine LTI propagation), E9d, E10a, E10b. E9d run 1 had invalid coverage statistics (a pseudo-inverse amplified numerical noise in the exactly-null columns of the hand-over map, factors up to 4.6e8); `coverage` now uses a relative rank tolerance and the experiment was re-run (run 1 kept as `e9d_run1_coverage_pinv.md`; its containment results did not use the pseudo-inverse). E9e (new) confirms on new seeds the earlier hand-over threshold found in E9c.
- **2026-11-13, stage E (RQ1 depth).** `AdaptiveResidual` and `RLS` (E8c), `generate_capture` and row-normalised fit (E8d; run 1 discarded most episodes with the tilt rule, kept as `e8d_run1_discard_rule.md`, rule replaced), MPC weight and terminal options (E8e), dictionary degree, sensor noise and sampling-period options (E8f), `truth_family("A+")`/`("B+")` with air-relative thrust and quadratic drag (E8g; tests show the default dynamics are bit-identical to the previous ones for the nominal plant and families A and B). The E8f commit message says 37 minutes of wall time; the measured wall time was 83 minutes.
- **2026-11-13, stage F (D8).** `rotorfail/mpc_cert.py` and E10c. A first closed form for the MPC feedforward used the infinite-horizon gain; the test against the actual QP showed that the finite-horizon QP has a time-varying feedforward, and the code was corrected before any result was produced.
- **2026-11-13, stage G.** Literature notes and search log (abstract level; primary texts not retrievable), novelty claims narrowed, `experiments/run_all.sh`, `experiments/audit_numbers.py`, paper in `docs/paper/`, report sections 09b and 11b.
- **2026-11-14, E9c figure deleted.** `results/figures/e9c_gain_synthesis.png` had an empty right panel (no redesigned certificate was found) and repeated colours, and no document used it. It was deleted together with its generation code in `experiments/e9c_gain_synthesis.py`; the table `results/tables/e9c_gain_synthesis.md` and the saved designs are unchanged and the script was not re-run.
